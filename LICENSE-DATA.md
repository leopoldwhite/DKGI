Data derived from STaRK with this code (the exported node and edge files, `schema.json`, `DATA_FORMAT.txt`,
and the question and label files written by `experiments/stark/prepare.py`), the per-query text-constraint tags in
`data/query_tags/tags_effective.jsonl` (model annotations of the STaRK query texts), and the prompt texts in
`prompts/`, are released under the Creative Commons Attribution 4.0 International License (CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/), following the license of the STaRK data release.
STaRK: Wu et al., "STaRK: Benchmarking LLM Retrieval on Textual and Relational Knowledge Bases", NeurIPS 2024
Datasets and Benchmarks Track (https://huggingface.co/datasets/snap-stanford/stark).

The tag file is the only data file in this repository. The exported graphs (yuyangbai/DKGI-STaRK-Graphs) and the trajectories (yuyangbai/DKGI-Trajectories) are distributed on Hugging Face under CC BY 4.0.
