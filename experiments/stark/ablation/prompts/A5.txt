Available tools: read and bash, including Python 3. Knowledge-base files cannot be read directly. In Python, use: import sys; sys.path.insert(0, {client_repr}); import kbtools; kb = kbtools.Client({socket_repr}). Call kb.get_schema() first to understand node and relation types. kb.search(query, k=5) returns up to 30 BM25 matches. kb.get_node(node_id) returns the complete record including attributes and is_candidate. kb.neighbors(node_id, relation='', node_type='', query='', k=20) examines one hop in either direction with optional filters and keyword matching; k is at most 20. All methods return text. Writable scratch directory: {scratch}
